
# NUR AI PRO 2.0

API-сіз жергілікті көмекші жүйе.

## Орнату

npm install

## Іске қосу

npm start

## Сайт

http://localhost:3000

## Әкімші

/admin

## API

GET /status

POST /api/chat

POST /memory/save

GET /memory/:userId

DELETE /memory/:userId

POST /admin/command
